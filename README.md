# C++ RPG Inventory System

A simple, object-oriented console application designed to manage in-game items like weapons, health kits, and armor. This project is built with C++ to demonstrate core OOP concepts such as classes, encapsulation, and vector manipulation.

## Features
* **Item Management:** Create items with specific properties (Name, Quantity, Rarity).
* **Capacity Control:** Prevents adding items if the inventory is full.
* **Display System:** Lists all currently held items in a clean format.

## How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/willbyers1/cpp-inventory-system.git](https://github.com/willbyers1/cpp-inventory-system.git)
   
Compile the code:
g++ main.cpp -o inventory

Run the executable:
./inventory
